# DevOps Certification Project

## Descripción

Aplicación web estática desarrollada como parte de un proyecto integrador de DevOps.

El objetivo es implementar un flujo reproducible de integración continua, construcción de imágenes Docker, publicación en un registry y despliegue en Kubernetes.

## Tecnologías previstas

- Git y GitHub
- GitHub Actions
- Docker y GitHub Container Registry (GHCR)
- Terraform
- Kubernetes
- Prometheus y Grafana
- Herramientas de análisis de seguridad SAST y DAST

## Estructura

- `src/`: código fuente de la aplicación.
- `tests/`: pruebas y validaciones automatizadas.
- `.github/workflows/`: pipelines de CI/CD.

## Estado del proyecto

Fase inicial: creación de la aplicación y preparación del repositorio.
